What you get

Zero install

Runtimes live in one folder in your user profile. No installer, no PATH or registry changes. Delete the folder to remove everything.

8 languages

JavaScript, TypeScript, Java, Go, PHP, C and C++ download as portable ZIPs the first time you use them.

Private and offline

Your code never leaves your PC. After the first download, everything works offline.

One file

A single script. Open source under the MIT license.

Quick start

Open PowerShell and run:

powershell -ExecutionPolicy Bypass -File .\FATYAK-Shell.ps1
